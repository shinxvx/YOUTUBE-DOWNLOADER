# Roadmap

- [x] Rules engine with tests, AI with 5 personalities, AI-vs-AI fuzzing
- [x] 80-card catalog: 33 creatures (8 three-stage lines, 6 single-stage, 3 legendaries), 24 techniques, 15 relics, 8 terrains
- [x] Three partners (Cindlet, Ripplet, Mossbit) with balanced starter decks
- [x] Island map with 8 open locations (+4 locked), Morning/Afternoon/Evening calendar
- [x] Act 1, "The Arrival": arrival, partner, lesson + tutorial duel, admission duel vs Ren, ceremony with Vael,
      demonstration vs Soren, the lighthouse pulse and the blank card, Initiate License
- [x] Dialogue with portraits, expressions and choices; Mira, Ren, Elara, Soren, Vael, Juno, Pip, Nell, Quill, Marlo
- [x] Deck editor (3 slots, filters, validation), collection, encyclopedia with lineages
- [x] Shop (packs with published odds, rotating singles), rewards, journal, messages
- [x] 3 tactical challenges (verified solvable by a solver), practice and friendly duels
- [x] Saves: autosave + 3 slots, atomic write, backup, versioning; settings; pause on focus loss
- [x] Electron Forge packaging (Windows app folder + zip built; Linux build run and checked)
