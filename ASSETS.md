# Assets: what is provisional

All art and audio in v0.1 is **provisional**. It is generated by code so the game is
complete and playable. Each file already has its final path and size, so it can be
replaced 1:1 without code changes.

| Asset | Path | Size | Source | Status |
| --- | --- | --- | --- | --- |
| Creatures (33 + "hollow" story sprite) | `public/assets/creatures/<id>.png` | 48×48 | `tools/creatures.py` | provisional |
| Portraits (13 characters × 5 expressions) | `public/assets/portraits/<who>_<expr>.png` | 64×64 | `tools/portraits.py` | provisional |
| Location backgrounds (12 + title) | `public/assets/locations/<id>.png` | 480×320 (painted at 240×160, 2×) | `tools/scenes.py` | provisional |
| Island map (normal / silenced) | `public/assets/map/island*.png` | 480×320 | `tools/scenes.py` | provisional |
| App icon | `build/icon.png`, `build/icon.ico`, `public/assets/icon.png` | 256×256 | `tools/scenes.py` | provisional |
| Technique / relic / terrain card art | drawn in code (`src/ui/cards.js`, `cardArt`) | — | code | provisional |
| Music (title, day, night, duel, tension) | `src/ui/audio.js` (`TRACKS`) | — | original chiptune, synthesized | provisional |
| Sound effects | `src/ui/audio.js` (`SFX`) | — | synthesized | provisional |
| Font | `@fontsource/pixelify-sans` (OFL) | — | bundled | final candidate |

Expressions: `neutral`, `happy`, `angry`, `surprised`, `sad`.

Run `npm run art` to regenerate every generated file (Python 3 + Pillow).
